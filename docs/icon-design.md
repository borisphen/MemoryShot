# App Icon Design

Иконка выбрана и зафиксирована. **Не менять без явного согласования.**

**Концепция:** нейронная сеть с молнией в центре.
Смысл: узлы = захваченные данные (голос + экран), молния = мгновенная обработка ИИ.

## Файлы

- `app/src/main/res/drawable/ic_launcher_foreground.xml` — foreground-вектор
- `app/src/main/res/drawable/ic_launcher_background.xml` — фоновая заливка
- `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` — адаптивная иконка
- `app/src/main/res/mipmap-anydpi-v26/ic_launcher_round.xml` — круглая адаптивная иконка

## Цвета

Вариант E — доступен при цветовой слепоте (нет красного/зелёного):

| Элемент         | HEX       | Описание    |
|-----------------|-----------|-------------|
| Фон             | `#212121` | Тёмно-серый |
| Узлы и связи    | `#FF6D00` | Оранжевый   |
| Молния          | `#FFFFFF` | Белый       |
